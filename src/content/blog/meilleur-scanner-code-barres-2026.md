Un bon scanner code-barres réduit les erreurs d'inventaire et accélère les ventes. Voici les critères essentiels avant d'acheter.

## 1. Filiaire ou sans fil ?

- **USB filaire** : idéal si vous travaillez sur un PC fixe ou portable au poste de stock. Moins cher, aucune batterie à gérer.
- **Bluetooth / sans fil** : utile pour parcourir un entrepôt ou une surface de vente. Vérifiez la portée et l'autonomie.

## 2. 1D ou 2D ?

Les scanners **2D** lisent les codes-barres classiques **et** les QR codes (étiquettes modernes, colis e-commerce). Pour Stockino, nous recommandons le **2D** pour rester compatible avec tous les formats.

## 3. Compatibilité avec Stockino

Stockino fonctionne dans le navigateur. Un scanner USB se comporte comme un clavier : il « tape » le code dans le champ actif. Aucun pilote complexe n'est nécessaire sur la plupart des postes.
