En boutique, le bon scanner dépend de **où** vous scannez : comptoir fixe ou rayon en mouvement.

## Comptoir / caisse : Honeywell MS7120 Orbit

Le [Honeywell MS7120](/hardware/honeywell-ms7120) se pose sur le comptoir. Le client ou le vendeur présente le code devant le lecteur — **mains libres**, scan rapide. Parfait avec Stockino sur un PC fixe.

**Limite** : codes 1D surtout ; peu adapté aux inventaires dans les réserves.

## Poste stock + caisse : Zebra DS2208

Le [Zebra DS2208](/hardware/zebra-ds2208) filaire USB convient au **poste arrière-boutique** : réception, inventaire, contrôle stock. Robuste et 2D (QR).

## Parcourir les rayons : Inateck BCST-21

Pour inventorier avec un portable sans câble, le [Inateck BCST-21](/hardware/inateck-bcst-21) sans fil est plus confortable.

## Synthèse

| Usage | Scanner |
|-------|---------|
| Caisse fixe | [Honeywell MS7120](/hardware/honeywell-ms7120) |
| Bureau stock USB | [Zebra DS2208](/hardware/zebra-ds2208) |
| Inventaire mobile | [Inateck BCST-21](/hardware/inateck-bcst-21) |

Stockino fonctionne dans le navigateur sur tous ces postes dès que le scanner est en mode **clavier (HID)**.
